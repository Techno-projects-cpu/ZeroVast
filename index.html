02 / Stack & capabilities

The tools behind
the work.

Every build starts from the platform: HTML, CSS and JavaScript, kept as small and as fast as the job allows.

01 / Languages

HTML5 and CSS3 for structure and presentation. Modern JavaScript for behaviour, SQL for data, and a little Python for build tooling and scripts.

HTML5CSS3ES2022+SQLPython
02 / Front end

Semantic markup, CSS Grid and custom properties, container queries, ES modules and progressive enhancement. Interactive where it helps, static where it doesn't.

GridCustom propertiesContainer queriesES modules
03 / Back end

Node.js, REST APIs, serverless functions and relational data in PostgreSQL or SQLite. Hosted platforms such as Supabase or Firebase when they earn their keep.

Node.jsRESTPostgreSQLServerless
04 / Tooling

Git and GitHub for version control, Vite for local development, VS Code, Figma handoff files, Chrome DevTools and Lighthouse for measurement.

GitGitHubViteDevToolsLighthouse
05 / Performance

Core Web Vitals budgets set before the build starts, critical CSS, modern image formats, sane caching and CDN headers, and a deliberate JavaScript budget.

LCPCLSINPCachingCDN
06 / Accessibility

WCAG 2.2 AA contrast, semantic landmarks, full keyboard support, screen-reader testing and visible focus states. Accessibility is part of the build, not a later pass.

WCAG 2.2KeyboardARIAFocus states

No framework is the default answer. React, Next.js or Tailwind only appear when the problem actually needs them — most of what I ship runs without a single dependency.

03 / How I work

Brief to handover,
without surprises.

Four steps, in the open. You always know what is happening and what happens next.

01

Brief

A call and a short brief. I ask what the site has to achieve and who it is for, rather than what it should look like.

02

Scope

Deliverables, timeline and terms written down before any code. You approve it, and that becomes the contract.

03

Build

Clean, commented, accessible code with a live preview you can open on any device, whenever you want to check progress.

04

Handover

You receive the repository, the deploy steps and a walkthrough. The site is yours outright — no lock-in, no seat licences.
